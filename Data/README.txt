GPRO Organizer
===============

GPRO Organizer is a community-maintained desktop companion tool for GPRO managers.

The application allows you to collect, store and analyze your game data locally on your computer.

--------------------------------------------------
DOWNLOAD
--------------------------------------------------

Latest releases:
https://github.com/MarFloCaro/GPRO-Organizer/releases

Download the latest ZIP file from the Assets section.

No installer is required.


--------------------------------------------------
INSTALLATION
--------------------------------------------------

New users:

1. Download the latest ZIP release
2. Create a folder for the application
3. Extract all files into that folder
4. Run:

   go.exe


Existing users:

1. Download the latest ZIP release
2. Extract files into your existing Organizer folder
3. Replace existing files when prompted

Important:
If your current tracks.dat file is newer than the release version,
do NOT replace it.

Your local data should remain preserved.


--------------------------------------------------
FIRST STARTUP
--------------------------------------------------

Recent releases include a tracks.dat file.

If GPRO adds a new track, tracks data may need to be updated manually.

Optional track update:

Tools -> Update tracks

The application will generate an updated tracks.dat file
and request a restart.


--------------------------------------------------
DOWNLOAD GAME DATA
--------------------------------------------------

After restarting:

Online -> Get All Data


--------------------------------------------------
SAVE YOUR DATA
--------------------------------------------------

After downloading your data:

File -> Save

The application will generate a go.dat file which stores
your local Organizer data.


--------------------------------------------------
NOTES
--------------------------------------------------

- All data is stored locally on your computer
- No cloud synchronization is performed
- Portable application, no installer required
- Legacy application under active maintenance and modernization
